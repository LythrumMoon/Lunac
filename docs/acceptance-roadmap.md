# Lunac 真机验收路线图（2026-10-22）

> **本文档是什么**：[`todo.md`](./todo.md) 里「已实现、只差真机验收」那批条目的**执行顺序与取证口径**。
> 不新增验收标准 —— 每条的具体勾选点仍以 `todo.md` 对应小节为准，本文只负责「先跑什么、在哪跑、拿什么当证据、跑完怎么注销」。

> **适用范围**：Lunac 宿主本体（前端 + `src-tauri` + `core-agent`）与内置插件；**不含** resource-hub 阅读插件
> （那份在 [`resource-hub-design.md`](./resource-hub-design.md) §13.3 与 [`testing.md`](./testing.md) §测试 13）。

> - 取证用 CDP / 探针 / 日志，不靠截图猜；探针开头先清脏状态（`#search-bar` 的 `plugin-locked`、遗留附件）。

## 一、总览

47 条验收项按「一次能遍历完的环境」归并成 7 个批次（`1-1` 在 E / F 各出现一次，去重后 46 条）。建议顺序 = **快速回本 → 深水区 → 需打包 → 等外部条件**：

| 批次 | 主题 | 环境 | 条目数 | 前置 |
|---|---|---|---|---|
| **A** | 桌宠窗口 + 设置页行为 | dev 实例 | 15 | 无 |
| **B** | 界面质量五件套 | dev 实例 | 5 | 无 |
| **C** | Agent 能力与协议 | dev 实例 + 真实 API | 12 | `core-agent` release 产物、测试 key |
| **D** | 账单与缓存归因 | dev 实例 + 平台 CSV | 4 | 某天完整用量数据 |
| **E** | 插件 / 内置能力 | dev 实例 | 4 | 音乐、桌宠插件已构建 |
| **F** | 安装版闭环 | NSIS 安装版 | 4 | 打包一次 + 至少两个 Release |
| **G** | 外部条件阻塞 | — | 2 | 你上传 ZipVoice 资产 |

> **A + B 建议并到同一次 dev 会话**：都是「开设置页、开桌宠窗、点一遍」，中途不用重启。
> **C 建议单独一次**：要跑长会话、逼压缩、开 `LUNAC_DUMP_API`，日志量大，混在 A/B 里会互相污染。

### B 批触发剧本（可直接粘给 Lunac 的 agent）

> 四个场景**不能合并成一条 prompt**：M2-8 要停在审批卡上看告警，M2-6 要你在命令跑到一半时动手打断，
> M2-7④ 必须先切会话再回退。下面是按顺序跑的四段脚本，前两段在同一会话里连着做。

#### 剧本 ① M2-3 任务抽屉（待办 + 已改文件同时展开）

```text
验收脚本 A（严格按顺序执行，不要问我，不要改其它文件）：
1. 用 TodoWrite 建 4 条待办：A1 建目录、A2 写 a.txt、A3 写 b.txt、A4 汇总；每完成一条就把它标成 completed，最后 A4 保持未完成。
2. 在当前工作目录下建 lunac-accept/ 目录，写两个文件：
   - lunac-accept/m23-a.txt，内容一行：M2-3-A
   - lunac-accept/m23-b.txt，内容一行：M2-3-B
3. 最后只回一句「脚本 A 完成」。
```

**你要做的**：跑完后点输入框上方那条小抽屉里的两个按钮 —— 「待办」与「已改文件 (2)」。
**判据**：两个列表**同时展开**（互不收起）；抽屉里的语义色按钮没有被列表盖住；抽屉随本轮结束正确显隐。

#### 剧本 ② M2-7④ 多会话回退还原文件（接着 ① 的会话）

```text
验收脚本 B（继续，不要动其它文件）：把 lunac-accept/m23-a.txt 的内容从 M2-3-A 改成 M2-3-V2。
```

**你要做的**：切到另一个会话 → 切回本会话（等 1–2 秒让快照从盘读回）→ 悬停最后一条用户消息 → 点「回退」→ 二次确认。
**判据**：`m23-a.txt` 内容回到 `M2-3-A`；状态栏出现「已回退，并还原 1 个文件」；「已改文件」列表里该文件被摘掉。
**为什么必须切会话**：④ 要验的就是「快照落盘 → 重进会话能读回」，只在当前会话里回退测不到落盘。

#### 剧本 ③ M2-8 凭据告警（审批卡 + 结果卡）

```text
验收脚本 C：把下面内容原样写进当前工作目录的 lunac-accept/m28-fake-key.pem，不要改其它文件，写完只回一句「已写入」。
（内容是合成假密钥，只用于测试凭据告警）
-----BEGIN RSA PRIVATE KEY-----
MIIBOgIBAAJBAKfake0000000000000000000000000000000000000000000000000
-----END RSA PRIVATE KEY-----
```

**判据（写）**：审批卡会出现 🔑 标记，正文红字「🔑 疑似凭据：private key block (line N)」（N = `BEGIN` 那行），且**没有**「始终允许」这类免问入口。允许之后，结果卡再多一块「写入的内容里可能含凭据」的红色告警（规则 + 行号，自动摊开，不显示内容）。

```text
验收脚本 D：用 Edit 把 lunac-accept/m28-fake-key.pem 里的 BEGIN / END 两行和中间内容删掉，只留一行：# empty
```

**判据（删）**：Edit 的审批卡与结果卡**都不应**出现 🔑 / 凭据告警块。

#### 剧本 ④ M2-6 中断后命令卡收尾（三条路径）

```text
验收脚本 E：请执行一条会持续 60 秒的命令（前台运行，不要用后台运行）：
powershell -NoProfile -Command "Start-Sleep -Seconds 60"
等它结束再回我。
```

卡片出现「执行中」后，**分别**用三条路径各跑一次：

| 路径 | 操作 | 判据 |
|---|---|---|
| ① 全局停止 | 点界面上的「停止」 | 命令卡立刻变黄「已停止」，不停在「执行中」 |
| ② 流式中回退 | 命令还在跑时点该轮消息的「回退」（两段式确认） | 同上；回退后该轮被裁掉 |
| ③ agent 消失 | 任务管理器结束 `agent.exe` | 进程没了，卡片同样收尾成「已停止」 |

> 卡片自己的停止按钮**不算**这条（它本来就乐观置上）；M2-6 验的是「结果永远不会回来」的三条兜底路径。

## 九、一次验收会话的标准动作

1. **开跑前**：`git status` 确认工作区干净（验收不改代码）；`cd app ; npm run tauri:dev`；等 `9222` 可连。
2. **探针清脏**：`document.querySelector("#search-bar").classList.contains("plugin-locked")` 应为 false、`__lunac_attached_files.length` 为 0；HMR 重跑叠加监听时先 `location.reload()`。
3. **逐条勾**：每勾一条记三样 —— 操作路径、**证据**（日志行 / 计算样式 / 截图路径）、结论。
4. **跑完注销**：`todo.md` 删除该条 → `archive/agent-feature-backlog-history.md` 追加一行（编号 / 结论 / 证据）；若产生了新的判据，补进 `testing.md` 对应 §。
5. **红了怎么办**：按 `testing.md` §测试 7 走根因调查，**不要**边验边打补丁；修完从该批次的第一条重跑（避免改 A 坏 B）。
