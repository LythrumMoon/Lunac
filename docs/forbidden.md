# 禁止事项（最高优先级）

> **本文档是什么**：Lunac 的**硬禁令清单**——只列「绝不允许」的事，每条附一句为什么。这是**最高优先级文档**，改动前先扫一遍。
>
> **取代了哪些旧文档的哪些章节**：散落在 `ai-spec.md` §8.3、§11 规则 1 / 2 / 9 / 12 / 14 / 18 / 21 / 23 / 26 / 38 / 45 / 46 / 47 / 49 / 51 / 59 / 61 / 62 / 67 / 68 / 73 / 76 / 78 / 80 / 88，`code-rules.md` 预检 #14 / #17 / #20 / #23 / #26 / #37 / #38 / #43 / #46 / #54 / #55 / #65 / #71 / #72 / #74 与第 5 / 11 章，`agent-ui-spec.md` §0 / §3 / §4.1 / §5.4 / §8，`icon-style.md` §4.1 的禁令条目。
>
> **历史细节见 `docs/archive/*`。** 现行规则怎么照做见 [`code-standards.md`](./code-standards.md) / [`ui-style.md`](./ui-style.md)。

## §禁用 1 安全与审批（动了就是安全承诺失真）

1. **不得自称「沙箱」**——Lunac 只有策略级边界（审批 + 工作区锁 + 危险命令黑名单），没有 OS 级隔离；包装成沙箱会让 `full` 档用户误判「有兜底」。
2. **不得让任何运行方式档位自动放行危险命令**——`CMD_BLACKLIST` / `analysis.dangerous` 命中时任何档位（含自动）都强制人工确认，且**永不提供「始终允许」**。
3. **不得让 hook 的 `allow` 越过两道硬闸**——hook 放行只等于「跳过审批卡」，静态安全分析命中 / 工作区锁 / 计划相位照旧。
4. **不得把「自动档」做成后端旁路**——审批的唯一决策点在前端 `classifyRequest()`；后端只上报 `analysis` 与「要不要问」。
5. **不得把本地路径传进需要 scope 白名单的命令**——`open_setting` 只收 `ms-settings:`、`run_system_action` 只认目录里的 id；也**不得**把本地路径写进 open scope（等于给所有插件开任意路径口子）。
6. **不得让白名单收纳解释器/启动器前缀**（`cmd` / `powershell` / `bash` / `python` / `node` …）——前缀匹配会把「任何 `powershell …`」都自动放行。
7. **不得把工作区锁例外做成「静默写入」**——例外只放行、不代替审批；`config\`（含 API Key）与 `Modules\` **不得**顺手放宽。
8. **不得让「接受」= 「确认写入」**——变更审阅是**事后**的，文件早写下去了；「接受」只标记已阅，「拒绝」= 用快照写回。
9. **不得对未信任的 `.mcp.json` / plugin sidecar 放行**——跟着仓库走的配置改一行 `args` 就能让本机跑任意命令。
10. **不得让插件直连端口或放宽 CSP `connect-src`**——HTTP 一律由宿主代请求；放宽 CSP 是对全前端 + 所有插件放宽。
11. **不得无面板常驻插件子进程**——界面上再没有地方能控制它，它就不该继续跑。

## §禁用 2 界面与视觉

12. **UI 文案里永远不得内嵌 emoji 当图标**——按钮标签 / 状态行 / 占位提示一律「纯文字」或「线性 SVG + 文字」（列表项图标与单色状态符号除外；任务抽屉连单色符号也不用）。
13. **不得使用原生 `<select>`**——WebView2 透明窗口不渲染它的弹层。
14. **不得写 `scrollbar-width` / `scrollbar-color`**——Chromium 见到非 `auto` 会整段忽略 `::-webkit-scrollbar`，滚动条退回系统默认。
15. **不得按容器单独声明滚动条样式**，也**不得藏滚动条**——统一细滚动条只有一处全局规则；新容器写 `overflow-y:auto` 即自动获得。
16. **不得用 `overflow: visible` 拆滚动容器**——加到「滚动条真正出现的那一层」会让 `scrollTop` 归零、再也滚不动。
17. **不得硬编码主题色 / rgb 分量**——凡 accent 带 alpha 必须写 `rgba(var(--accent-rgb), x)`；中性叠加走 `--ink-rgb` / `--shade-scale`；面板/菜单/抽屉底色走 `var(--surface-glass)`。
18. **不得把语义色（红绿黄蓝）塞进 accent**——动作按钮跟随主题色，语义状态色固定。
19. **不得在渲染点写死颜色或逐元素改 `style`**——主题色 / 主题包只经 CSS 变量落地，图标只走 `pluginIconSvg()` 一个出口。
20. **不得新增主题切换机制**（本轮只有一套深色）；**不得回退**「风格」三处既定形态（背景自定义 = 展开五个拉条；取色器应用内自绘；分组小标题样式）。
21. **不得给审批卡命令区加复制按钮**（命令文本本身可选中）；**不得**再给卡片加第二个「取消」按钮。
22. **不得给审批卡命令区叠第二层滚动容器**——滚动只由 `.approval-batch-body` 承担。
23. **不得在 `#chat-log` / `.agent-flow` 里拼带缩进换行的 `innerHTML` 模板**——`pre-wrap` 继承会把缩进渲染成幽灵空行。
24. **不得把「自动允许 / 已复制」类提示加回对话流**——没有审批卡就是自动放行，一轮能刷十几行纯噪音。
25. **不得用「模型摘要」替换计划卡原文**——那张卡是放行写类工具的唯一依据，摘要可能藏起风险；长计划用折叠。
26. **不得折叠命令卡**——完整命令是安全要求，用户要看清到底执行什么。
27. **不得让单个块无限拉长**（长内容必须在自己块内折叠）；不得引入横向滚动；不得出现第二层滚动条。
28. **不得新增 `setSize` 调用或把插件态/详细搜索态拉进高度滑动动画**。
29. **不得把控件放进 `#status-bar`**（那里已有 token 面板，高度受限）。
30. **不得用 `scrollIntoView` 让当前提问节点进视野**——它会连 `#results-list` 一起滚，抖掉正在读的位置。

## §禁用 3 前端代码

31. **不得在插件里 `fetch()` 远端**——CSP `default-src` 不含远端域会被拦；一律加宿主命令去请求。
32. **不得对 `result.usage` 做差**——自研 agent 每次提问给的是绝对值；累计是前端的事。
33. **不得硬编码中文/英文文案**——一律走 `t()` 且补齐翻译。
34. **不得用动态 `import()` 加载事件 API**——要监听的事件必须静态 import 确保就绪。
35. **不得依赖 `innerHTML` 恢复 checkbox 等交互状态**——序列化不保留 DOM property；跳过缓存重跑 `execute()`。
36. **不得用 `requestAnimationFrame` 断言布局完成**、不得用 `scrollHeight` 测量决定窗口尺寸（WebView2 视口会裁剪）。
37. **不得在流式回调里省掉 `streamId` 守卫**——关闭后旧数据会污染新对话 DOM。
38. **不得让渲染函数覆盖已打开的插件面板**（`pluginActive` 必须守卫）。
39. **不得用 `opacity:0` 隐藏 overlay**——仍占 DOM 拦点击，要 `remove()`。
40. **不得用摘要/时间戳猜用量归因**——归因字段（`sessionId` / `source`）由采集侧显式写入。
41. **不得把「每界面一个 AtomicBool + Esc 加一条 else if」**——界面层用唯一 `UI_MODE` 枚举 + 唯一出口 `syncUiMode()`（且**不得给它加去重缓存**）。

## §禁用 4 后端 / 子进程 / 构建

42. **不得在非 async `#[tauri::command]` 里做阻塞 IO**（网络 / 子进程 / 图标 / OCR / 大文件）——跑在主线程会「应用程序未响应」；也不得用 `#[tauri::command(async)]` 顶替（要 `run_blocking`）。
43. **不得用 `is_err()` 守卫注入环境变量**——`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 必须读现值**合并**追加，否则外部预设会让自己的旗标全部静默失效。
44. **不得加 `--disable-gpu` / `--single-process` / `--in-process-gpu`**——`--disable-gpu` 换软件光栅化（本 UI 有 10 处 `backdrop-filter`）；后两个非官方 / 不支持。
45. **不得把易变块放回 `system` 系统提示词**（往期会话索引、记忆块）——它们随会话增长而变，放回去会让每次重启后前缀整段 miss；应注在 history 开头。
46. **不得恢复任何形式的「自动注入往期会话内容」**——它会让新建对话带上个对话的痕迹。
47. **不得用 `localStorage` 承载 AI 配置**——它不在 exe 根、dev 与 release 各存一份，会导致「key 改了不生效」。
48. **不得无条件安装 LL 键盘钩子**——会引入 AV 误报（键盘记录器特征）+ 游戏失效；LL 回调内**不得手动 down/up 跟踪 Alt**。
49. **不得让 agent stdout 走非协议内容**——那是 stream-json 协议流，日志只能落盘。
50. **`.ps1` / `.nsi` 不得丢 BOM 也不得多 BOM**（恰一份）；改完必须跑 `npm run verify`。
51. **不得把某个磁盘插件写进主 bundle 的 import 或 `id === "xxx"` 分支**——会破坏「卸载 = 完全不存在」。

## §禁用 5 仓库与分发（违反=密钥泄露或侵权，不可撤销）

52. **上游 CLI 源码绝不入库**（现在 `_reference/core/`，整目录 gitignore）。
53. **`.env` 绝不入库**——含真实凭据；只提交 `.env.example`。
54. **大二进制不入库**（GitHub 单文件 100MB 上限）。
55. **上游 `cli.exe` 绝不进安装包**，也不得随任何发行包分发。
56. **插件只带引擎与逻辑、不带模型数据**——模型一律由用户导入。
57. **不得引入违规转载的 `live2dcubismcore` npm 包**（含 Haru 样例模型却标 ISC），Core 要走自托管带版本副本 + 随附授权文件。

## §禁用 6 日志与凭据

58. **日志里不得出现完整凭据**——任何进日志的字符串都要过 `mask_secrets()`；凭据只记末 4 位（`key_tail=`，不得写成 `key=` / `api_key=`）。
59. **不得把原始错误（状态码 / URL / JSON 响应体 / 异常类名）贴进界面**——进日志，界面只说「哪一步没成 + 用户能做什么」。
60. **不得把开发者向数据（路径 / 版本号 / 字节数 / 哈希 / 端口 / 进程名）放进主界面**——要留就放进「详情 / 开发者选项」二级入口。

## §禁用 7 数据与状态

61. **不得在 `chat.db` 混入大块用户文件内容**（文件快照落独立 `frames\*.json`）；**不得**把本地判定写进会话消息（决策账本独立落盘）。
62. **不得让同一个值有两份实现**（见 [`code-standards.md`](./code-standards.md) §规范 2）；改一处必须回头改另一处。
63. **不得用 `dedup_by` 去重同名条目**（排序键含来源优先级，重复项不相邻，会漏）。
64. **不得在文件一变就杀 agent 进程**——重启要按空闲分流；且**不得静默重启**，要如实交代「本回合用的是旧配置」。
65. **不得让「往 history 里塞东西」的路径绕过预算/上限**——一条失控命令的 stderr 可以任意大，会每轮都 miss。
