1. 系统总览

Lunac 是“主控芯片”：一个 Tauri 宿主 lunac.exe、一个自研 Agent 后端 agent.exe，以及三类插件形态。

三条信道：WebView 插件 → __lunac_host / postMessage；插件 sidecar → stdout NDJSON 或宿主代请求；Agent → stdio stream-json + MCP。

5. 插件生态与能力门

插件包结构

Modules/<id>/
├─ lunac-plugin.json
│    id / version / permissions
│    provides / dependencies
│    window / sidecar / render / dev
├─ index.js              DOM 引擎入口
├─ ui/index.html         iframe 引擎入口（可选）
├─ server/*.exe          sidecar（可选）
└─ .toolchain/           用户授权的工具链（可选）

宿主桥（apiVersion 3）

__lunac_host
├─ t / apiVersion
├─ sidecar
├─ net.request      ← permissions: ["net.fetch"]
├─ storage          ← permissions: ["storage.plugin"]
├─ media.proxy      ← permissions: ["media.proxy"]
└─ engine.eval      ← permissions: ["engine.eval"]

能力与信任边界

能力门 / 边界
process.spawn信任卡，默认拒绝；sidecar 可设内存 / 进程数上限
net.fetch能力门 + 只允许 http(s) + 拒绝本机 / 私网 + 超时 / 体积上限
media.proxy能力门 + 只代理公网 + 转发 Range + 重定向逐跳复检
storage.plugin能力门 + 按 id 隔离 + 配额 + 卸载即清
engine.eval能力门 + QuickJS 无宿主绑定 + 超时 / 内存上限；不是 OS 沙箱
dev 工具链只有用户能授权；按清单指纹失效；永不自动安装 / 构建

iframe 是 DOM / CSS / 脚本作用域边界，不是安全沙箱；插件本质上是本机可执行代码。
