## 一、视觉描述原文（模型输出，保留不改）

### 1. 人物与气质

画面主体是一位偏侧身（约四分之三侧面）的女性人物，气质偏清冷、疏离、空灵与忧郁。人物面部轮廓细腻，眉骨微压、眼睑半垂，目光向下偏左，带有一种沉思或易碎的情绪。她身着偏奇幻风格的服饰：头顶戴着如蓝水晶或水膜般异化的兜帽，发丝与流线型的面纱相互缠绕；胸前有类似蝴蝶羽翼的金属或水晶饰物，脖颈与耳畔佩戴着由碎钻、金属珠链与宝石构成的复杂首饰。整体风格联想偏向「暮光」、「水泽精灵」或「废墟中的神明」，带有浓厚的二次元插画与奇幻设定感。她的姿态并不张扬，但衣物和发丝的走向极具向外扩张的张力，形成了一种「静中有动」的矛盾美感。

### 2. 构图与空间

- **视线**：主体视线向左下方，构成一条引导观者看向画面左侧边缘的视觉线。
- **留白**：左实右虚。人物集中在左侧及中偏左位置，右侧留出大面积偏烟蓝色和灰色的背景空间。
- **前后景层次**：前景是清晰、高锐度的面部与项链；中景是飘逸交织的发丝与右侧的几只白色蝴蝶；背景是虚化、混沌的蓝灰色水波纹或烟雾状肌理。
- **重心**：落在人物的侧脸、颈部金属项圈以及胸前带有蝴蝶元素的配饰上（画面左下方）。
- **节奏**：疏密有致。面部留白多（疏），颈部和头部首饰极多（密）；发丝与背景的笔触是流动的长线条（舒展），碎钻与蝴蝶的点缀是短促的点（跳跃）。整体如水波荡漾、烟雾弥漫的轻缓节奏。

### 3. 笔触与肌理

- **绘画语言**：印象派水彩 / 水粉与厚涂交织；背景有明显的湿画法晕染痕迹。
- **边缘处理**：面部与五官边缘清晰（硬边缘）；衣服和头发末端使用「飞白」（干笔刷擦过的枯笔）与破碎边缘（软边缘 / 逸散边缘），呈现拉丝感和未画完的速写感。
- **颗粒感**：头发和背景的深色区域有明显的胶质或画布粗糙颗粒感。
- **画布质感**：背景隐约可见画布纹理；光影与色彩交界处呈现水渍干涸后的水痕边缘（水彩叠色技法）。

### 4. 色彩与光线（仅作气质参考，**不用于页面底色**）

- **主色倾向**：以蓝为基调（海蓝、靛蓝、水蓝），辅以银白、水墨灰、极少量紫罗兰；高光偏近白的亮银。
- **明暗对比**：中等对比度。面部受光面极亮，阴影溶于灰蓝色环境光，不压死黑。
- **光源方向**：偏左上方，打在额头、鼻梁、左侧脸颊与肩头。
- **反光与阴影**：阴影偏冷（灰蓝）；金属 / 水晶有冷暖交替的微弱高光。

> **提纯结论**：只保留「高光闪烁、暗部透气」的光影逻辑，舍弃整套蓝白色系。

### 5. 图标转译规范（印象化 UI 图标）

- **线条粗细**：24×24 viewBox 中基础线宽 1.5~2px；12px 显示时视觉重量约 1px。
- **笔触断点**：不做绝对封闭的完美几何；每个图标保留 1~2 处断点 / 飞白缺口，占轮廓总长 10%~15%。
- **端点与拐角**：圆头端点；拐角 0.5~1px 小圆角，避免尖锐直角。
- **点彩 / 残影 / 飞白比例**：飞白与断点 10%，点彩 5%，残影 5%。
- **填充比例**：整体 30%~40%，用半透明填充或「线框 + 局部实心」。
- **单色层级**：两级单色（主结构深灰、辅助 / 高光浅灰白）。
- **选中态**：不用纯色块反白；选中时边缘出现「水彩晕染 / 光晕」的微膨胀，线条色加深或带柔和色相偏移投影。

具体画法（24×24）：

- **搜索**：放大镜圆框不画满，右上角留飞白缺口；手柄不是直线，而是略带波纹的弯线，末端如笔触消散；镜内点缀 1~2 个微小圆点（模拟碎钻）。
- **应用**：四个小方块边缘不完全水平垂直，允许轻微歪斜 / 圆润；其中两块之间用一条极细的「飞白线」连接。
- **AI**：抽象发光星芒或大脑节点；中心不规则小圆，向外三根线，其中一根末端断掉，另一根分出墨滴状圆点；线条呈「快写、断续」的速写感。

### 6. 动效转译规范

- **整体节奏**：慢、轻、有停顿的呼吸感；隐喻微风拂发、水波荡漾、蝴蝶振翅。
- **缓动曲线**：偏 `cubic-bezier(0.25, 0.1, 0.25, 1)` / `ease-in-out`；拒绝匀速与弹簧回弹。
- **入场**：淡入 + 上浮 4px + 轻微虚化散去，600ms。
- **退场**：快速淡出 + 轻微缩放大，400ms。
- **切换**：溶解 / 残影为主，500~700ms。
- **加载**：描边流动或断点飞白呼吸，2000ms 一轮。
- **循环关键帧示例（1000ms）**：0~40% 上浮入场（opacity 0→100%、blur 4→0）；40~60% 静止；60~80% 高光 / 飞白轻微闪烁（100%→80%→100%）；80~100% 静止。
- **禁止**：弹跳 / 回弹 / 快速闪烁与旋转；强硬边缘裁切或像素级跳变；高饱和渐变。

### 7. 印象化 UI 的三条原则与三条反例

**原则**

1. **留白大于填充**：像画面右侧的虚空，界面保持通透留白（空白率建议 ≥50%）。
2. **触感大于几何**：不规则边缘、飞白、颗粒传达「手作温度」。
3. **律动大于位移**：动效重心是光影、透明度、模糊度的渐变流淌，而不是元素从哪里滑过来。

**反例**

1. 过度肌理堆叠（满屏毛玻璃 + 水渍，可读性崩溃）。
2. 半透明滥用（底层线条透出，层级混乱）。
3. 拖沓动效（为了「空灵」把所有动画拉到 1s 以上，产生延迟感）。

## 二、页面配色：不取自图片，走「简洁 / 易读 / 大气」

### 2.1 取向

- **中性石墨底**：去掉原主题的绿 / 蓝 / 玫瑰色相，底色只留极轻的冷灰倾向。
- **暖白文字**：正文接近纯白但不是纯白（避免刺眼），三档文字对比度全部高于 WCAG AA。
- **香槟银唯一高亮**：accent 面积 ≤5%，只出现在焦点、选中、进行中。
- **低装饰**：不使用图片背景、不使用花纹（`pattern_opacity` 保留但默认无图）、不做厚阴影。
- **留白**：结果行仍为 56px 高（行数 ×56 的窗口纪律不变），靠 12px 图标—文字间距与 14px 左右内边距制造呼吸感。

### 2.2 最终 token

| 变量 / 字段 | 取值 | 说明 |
|---|---|---|
| `--surface-rgb` / `theme.json surface` | `22, 24, 27`（#16181b） | 中性石墨底 |
| `--surface-rgb-hover` | `42, 45, 49`（hover = +20/通道） | 悬浮底 |
| `--surface-alpha` 默认 | `1` | 用户手工调整值，已定为默认；面板不透明以保证易读 |

### 2.3 不使用的东西

- 图片中的蓝 / 青 / 紫主色，以及高饱和渐变。
- 背景图片、厚重毛玻璃、水渍纹理、满屏颗粒。
- 弹簧 / 回弹 / 过冲动画。

## 三、图标：印象化但必须可读

### 3.1 规范

- **线宽**：保持 `stroke-width="2.2"`（24 viewBox、12px 显示 ≈1.1px），与描述中的「12px 屏幕约 1px」一致；**不得**直接写 1.5。
- **断点 / 飞白**：只用于**装饰性图标与新建图标**；搜索、应用、AI 这类高频功能图标允许 0~1 处小缺口，且缺口不得破坏识别。12px 下缺口小于 1px 会糊成断线，所以实际只保留「端点不闭合」的轻微处理。
- **端点 / 拐角**：`stroke-linecap="round"`、`stroke-linejoin="round"`，拐角半径靠圆角线帽表达。
- **残影 / 点彩**：沿用现有语言（同形副本偏移 -0.6~-0.7、opacity 0.28；点彩圆点 r≈0.9）。这是本描述里「残影 5% / 点彩 5%」的既有落点。
- **单色层级**：图标默认 `--text-dim`；hover / 选中走 `--other-overlay-rgb`（§界面 2 既有纪律）。
- **选中态**：图标容器叠加 10% 同色低透明填充（`.result-item.selected .result-item-icon`），表达「水彩晕染微膨胀」，不做反白色块。

### 3.2 具体落地

| 图标 | 本轮动作 |
|---|---|
| 搜索 | 不放新图；保留现有形态。若后续重绘：圆框右上留 1px 缺口、手柄末端轻微上翘、镜内 1 个点彩圆点 |
| 应用 | 保留现有方块族；四块之间不加连线（12px 下会糊） |
| AI | 保留现有星芒；节点圆 + 一条断线即可 |
| 结果行图标 | 选中时容器底色 4% → 10%（同色）；hover / 选中加 `drop-shadow(0 0 2px rgba(var(--ink-rgb), 0.16))` 柔光，模拟笔触边缘光晕 |
| 顶栏 / 输入栏图标 | 只换颜色继承（新 accent / text-dim），不改路径 |
| 搜索栏装饰层 | **不做**（2026-10-18 用户裁定）：蝴蝶饰带 `#search-bar-filigree` 与退场固定层 `#exit-ornament` 已整体删除 |

## 四、动效：水彩呼吸，但不超过 900ms

### 4.1 曲线与时长

| token | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(0.25, 0.1, 0.25, 1)` | 常规进出（水感 ease-in-out） |
| `--ease-collapse` | `cubic-bezier(0.7, 0, 0.84, 0)` | 收拢 / 加速退场 |
| `--motion-fast` | `160ms` | 微交互 |
| `--motion-base` | `280ms` | 常规过渡 |
| `--motion-slow` | `520ms` | 面板级过渡 |

### 4.2 四类动效

| 类别 | 设计 | 落点 |
|---|---|---|
| 入场 | 淡入 + 上浮 4px，600ms；不做 blur（WebView2 上整列表 blur 会掉帧） | `lunac-window-shown` 后给 `html.is-booting` 620ms，`#results-list` 容器播放 `result-boot`（作用在容器上，避免打字时逐行重播） |
| 退场 | 执行搜索结果：画卷式上下拉缩，900ms（见 4.3） | `launchApp` / `web-search` |
| 切换 | 插件面板沿用现有即时切换；不新增长溶解 | 不改 |
| 加载 | 沿用现有 `lunac-spin`；飞白呼吸只在将来新增的 loading 图上使用 | 不改 |

### 4.3 搜索结果退场（900ms，2026-10-18 三次定稿：画卷式拉缩 + 60px 聚焦卡）

| 时间 | 对象 | 效果 |
|---|---|---|
| 0~495ms（0~55%） | 整个页面 `#app` | `clip-path: inset()` 上下裁切，从整页收拢到被点结果所在的 60px 横带；宽度不变、内容不缩放、不淡出 |
| 495~900ms（55~100%） | `#app` | 保持 60px 横带 |
| 0~900ms | `#exit-focus-card` | 被点结果克隆成的 60px 高固定卡，不缩放、不淡出 |

- **为什么用 `clip-path`**：`scaleY` 会把文字与图标一起压扁；`clip-path` 只裁显示区域，内容尺寸不变，形成「画卷上下收拢」的观感。
- 被点行加 `.is-exit-source` 并 `opacity: 0`，由固定卡接管，避免重影。
- 60px 横带的上下裁切量由 JS 写入 `#app` 的 `--exit-clip-top` / `--exit-clip-bottom`；坐标统一除以 `currentZoom`（`getBoundingClientRect` 给视觉像素，fixed / clip 用布局像素）。
- 应用启动在 **405ms**（动画中段）发出，隐藏放在 **900ms** 末尾；固定卡不淡出，随窗口隐藏一起消失。
- 全程无 `filter: blur`、无蝴蝶饰带固定层，保证 60fps。
- `prefers-reduced-motion: reduce` 时页面压缩跳过，直接隐藏。

### 4.4 禁止项

- 弹跳 / 回弹 / 过冲。
- 快速闪烁、旋转（loading 已有专用 spin）。
- 时长超过 1s 的界面动效（本主题上限 900ms）。
- 为了动效给 `#search-bar` 加 `transition`（打字性能，§界面 9 / 18）。

## 六、与现行规范的冲突裁定

| 冲突点 | 裁定 |
|---|---|
| 描述要求线宽 1.5~2（viewBox） | 保留 2.2：12px 显示 ≈1.1px，符合「屏幕 1px 视觉重量」；直接写 1.5 会糊 |
| 描述要求每图标 1~2 处断点 | 只对新建 / 装饰图标执行；高频功能图标 12px 下断点会破坏识别 |
| 描述要求 30%~40% 填充 | 仅选中态图标容器用 10% 同色低透明填充；不做整图填充（会与四类颜色纪律冲突） |
| 描述要求入场 600ms + blur | 保留 600ms，去掉 blur（整列表 blur 掉帧）；用 opacity + 4px 位移 |
| 描述要求退场 400ms | 搜索结果退场按用户三次定稿保留 900ms（画卷式裁切到被点结果的 60px 横带 → 保持）；普通控件退场仍 160~280ms |
| 页面配色是否取图 | **不取**。页面走中性石墨 + 暖白 + 香槟银；图片只供 icon / 动效气质 |
