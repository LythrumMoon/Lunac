# Lunac 技能目录（skills）

把你自己的技能放进这个目录，agent 启动时会扫描它，并且**只把「名称 + 描述」列进系统提示词**（渐进披露）；模型判断需要时才调用 `Skill` 工具取回正文 —— 所以技能再多也不会把上下文撑爆。

## 目录结构

```
skills\
  <技能名>\
    SKILL.md          ← 必须叫这个名字，否则整个目录会被跳过
    ...               ← 该技能自带的脚本 / 参考资料，正文里用相对路径引用
```

## SKILL.md 格式

```markdown
---
name: my-skill
description: 一句话说明这个技能做什么、什么时候该用它（≤ 250 字符）
---

正文（Markdown）。写清楚步骤、约束和示例。

可以用 `$ARGUMENTS` 占位符：用户调用技能时传的参数会替换到这里。
```

## 生效方式

- 在 Lunac 设置 ·「技能扩展」面板里增删改 → 面板会自动重启 agent，立即生效。
- 直接改这个目录的文件 → 需要重启 Lunac（或切换一次思考档位）让 agent 重新扫描。
- 技能清单**按目录名排序**后拼进提示词（顺序抖动会整段作废端点侧的前缀缓存）。

## 关于本目录里的示例

`_example\SKILL.md.example` 是一份可以直接照抄的模板。它**故意不叫 `SKILL.md`**，所以不会被加载、也不会出现在模型看到的清单里 —— 想启用就把它改名成 `SKILL.md`。
